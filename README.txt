WEBSITE ULANG TAHUN AZIZAH (dari Khosyi)
=========================================

CARA MEMBUKA
- Klik dua kali index.html (terbuka di browser). Butuh internet hanya untuk memuat font cantik dari Google Fonts.

GANTI FOTO
- Taruh foto di assets/photos/ dengan nama foto1.jpg sampai foto6.jpg.
- Caption foto diubah di index.html (cari tag <figcaption>).

GANTI MUSIK
- Bawaan: melodi music box lembut buatan sendiri (tanpa file).
- Mau lagu favorit? Taruh file MP3 dengan nama assets/music.mp3 (otomatis dipakai).

GANTI ISI UCAPAN & SURAT
- Buka index.html, edit teks di bagian "Ucapan Kecil dari Hati" dan "Surat Rahasia".

AGAR BISA DIBAGIKAN LEWAT LINK
- Upload seluruh folder ke Netlify Drop, GitHub Pages, atau Vercel, lalu kirim link-nya ke Azizah.
